# Paper Review Benchmark

APRES Paper Review benchmark adapted from `hyperagents`. Prompts are based on the `meta-hyperagents` paper_review domain (which was itself originally adapted from SakanaAI's AI-Scientist `perform_review.py`). All from: https://arxiv.org/abs/2603.03142

This repository is primarily used for CodeEvolver research as a seed program to be optimized.
